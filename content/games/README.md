# Авторские материалы для игровых занятий

Полное тематическое покрытие GoGetter 3 (вводный + 8 разделов) и 115 разделов Essential Grammar in Use, 4-е издание. Advanced Grammar in Use в этот выпуск не входит.

Источники для сверки тем находятся локально в `books/`: Student’s Book и Workbook GoGetter 3, Essential Grammar in Use 4th Edition. PDF не копируются в приложение, Git или архив публикации. Номера страниц в каталоге — печатные страницы Student’s Book / Essential, не индекс страницы PDF.

`essential.txt` и `gogetter.txt` содержат самостоятельно составленные ситуации с ключами, отвлекающими вариантами и краткими объяснениями. В каждой теме четыре грамматические ситуации представлены в двух контекстах с разными именами/местами. Это восемь фраз и восемь вопросов; материал повторно используется в разных игровых механиках, а не выдаётся за 2782 независимых учебных сюжета. Для Essential добавлены шесть пар «предложение с пропуском → завершённое предложение», для GoGetter — двенадцать лексических пар с русским переводом из `vocabulary.json`.

Общий объём: 124 набора, 992 фразы, 992 вопроса и 798 пар — 2782 игровых элемента. Наборы подходят для всех пяти механик. Дополнительные повторения из Workbook представлены в тех же темах, а не отдельным дублирующим курсом. Это тренировка грамматики и лексики, а не цифровая копия каждого упражнения, аудио или видео учебника.

## Формат и проверка

Одна строка исходного текста: `номер|тема|объяснение|четыре ситуации через ;;`. В квадратных скобках — правильная форма и два отвлекающих варианта, разделённые `~`. Контекстные маркеры `{N}`, `{M}`, `{D}`, `{P}` заменяются при сборке. Примеры составлены заново; диалоги, иллюстрации и упражнения издателей не воспроизводятся.

`npm run games:build` обновляет `bank.json`. `npm run games:check` проверяет соответствие банка исходникам без изменения файлов и автоматически выполняется перед сборкой приложения. Тесты проверяют полноту разделов, минимальное наполнение, уникальность контекстов, ключи и совместимость всех наборов с каждой механикой. Ответы и примеры сверяются при редактировании; автоматические проверки структуры не заменяют языковую редактуру.

Преподаватель может открыть набор в редакторе, скопировать, адаптировать под ученика и сохранить. Авторские пользовательские копии находятся в PostgreSQL и не перезаписываются при обновлении стартового банка.
